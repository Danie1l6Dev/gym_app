# Scrum y Trello

## Organización sugerida

Columnas mínimas en Trello:

- Backlog
- Sprint 2
- In Progress
- Review
- Done

## Definition of Done

Una tarjeta puede cerrarse cuando:

- El código está implementado.
- El contrato backend/frontend está alineado.
- No quedan datos de prueba rotos.
- Las pruebas o verificaciones relacionadas pasan.
- La documentación mínima se actualizó si el cambio afecta uso, instalación o API.

## Sprint 2 listo para cerrar

Estas tarjetas pueden marcarse como Done con el estado actual del repositorio:

- Unificar contrato de membresías.
- Corregir seeders de usuarios, membresías, ejercicios y rutinas.
- Aplicar migración pendiente de ExerciseDB.
- Reemplazar pruebas backend de plantilla por pruebas funcionales.
- Crear README raíz y documentación mínima.
- Corregir textos dañados por codificación.
- Conectar Home a datos reales disponibles.
- Resolver Perfil sin placeholders falsos.

## Pendiente para siguientes tarjetas

- Formularios frontend de alta/edición de membresías.
- Edición y eliminación de rutinas desde frontend.
- Pruebas frontend.
- Exportar diagramas a imagen o PDF si se requiere entrega formal.
