# Alcance funcional

## Incluido actualmente

- Inicio de sesión con email y contraseña.
- Persistencia de sesión en el frontend.
- Rutas protegidas para usuarios autenticados.
- Rutas protegidas para administradores.
- Consulta pública de músculos y ejercicios.
- Creación, consulta, actualización y eliminación de rutinas desde la API.
- Creación y consulta de usuarios desde el panel admin.
- Consulta y creación de membresías desde la API.
- Consulta de membresías próximas a vencer.
- Sincronización administrativa de ejercicios desde ExerciseDB cuando las variables externas están configuradas.

## Pendiente para siguientes sprints

- Formularios frontend para crear o editar membresías.
- Edición y eliminación de rutinas desde el frontend.
- Endpoint específico para dashboard admin si se decide mover el cálculo desde el frontend al backend.
- Más cobertura de pruebas frontend.
- Documentación visual exportada si el docente exige imágenes o PDF además de Mermaid.

## Fuera del alcance actual

- Pagos reales.
- Control de asistencia.
- Planes de entrenamiento con seguimiento histórico.
- Notificaciones push.
- Recuperación de contraseña.
